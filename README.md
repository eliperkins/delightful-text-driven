# Delightful Text-Driven Experiences with SwiftUI's `TextRenderer`

## Abstract

Great apps sweat the small details, and text rendering is no exception. Since its introduction in iOS 18, I've enjoyed playing with SwiftUI's TextRenderer to create interactive text experiences that go beyond black-and-white pixels on screen. By combining animation, real-world user-generated text, and some SwiftUI know-how, TextRenderer can make your app truly sing.

In this talk, I'll share what I've learned shipping text-driven features in Particle News, from animated audio transcripts to progress-driven animations that can energize any SwiftUI app.
